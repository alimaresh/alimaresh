# Setup instructions

## 1. Create the special profile repository

Create a new **public** GitHub repository with this exact name:

```text
alimaresh
```

The repository name must exactly match your GitHub username.

## 2. Upload the files

Upload these files while preserving the same structure:

```text
alimaresh/
├── README.md
├── PINNED_REPOSITORIES.md
└── assets/
    ├── header.svg
    ├── truborankai-card.svg
    ├── efootballlab-card.svg
    └── plinkod-card.svg
```

## 3. Make sure the profile README is enabled

When GitHub detects `README.md` inside the public `alimaresh/alimaresh` repository, it will automatically display it at the top of your profile.

## 4. Pin the best repositories

Open your GitHub profile, select **Customize your pins**, and pin the repositories listed in `PINNED_REPOSITORIES.md`.

## 5. Recommended final checks

- Confirm all images load correctly.
- Test all website and social links.
- Remove any technology you no longer use.
- Update the **Currently building** section every one or two months.
- Add real product screenshots later if you want to replace the illustrated cards.
